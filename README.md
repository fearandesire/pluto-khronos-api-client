# pluto-khronos-api-client

Generated TypeScript client library for the Khronos API used by Pluto.

## Development

```bash
npm install
npm run generate
npm run build
npm test
```

The checked-in OpenAPI document lives at `/openapi/khronos.openapi.yaml`, and the generated client is written to `/src/generated`.
Replace or update that OpenAPI file as Khronos' spec changes, then regenerate to keep Pluto's client in sync.
